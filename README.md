# 🐾 Amigos de Patas

Projeto desenvolvido para a atividade prática do curso de Análise e Desenvolvimento de Sistemas (ADS), da Universidade de Marília (UNIMAR).

## Sobre o projeto

O Amigos de Patas é um site desenvolvido para representar uma ONG de proteção animal. O objetivo é divulgar a importância do cuidado com os animais e incentivar a adoção responsável.

## Funcionalidades

- Página inicial da ONG.
- Apresentação do trabalho realizado pela organização.
- Imagem de um cachorro e um gato.
- Integração com uma API.
- Exibição do status de funcionamento da API.
- Exibição da data e hora atual.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vite+
- Node.js
- Express
- Dotenv

## Como executar o projeto

1. Instale as dependências:

   `pnpm install`

2. Inicie a API em um terminal:

   `pnpm api`

3. Em outro terminal, inicie o site:

   `pnpm dev`

4. Acesse no navegador:

   `http://localhost:5173`

## Teste da API

Acesse:

`http://localhost:5173/api/health`

A resposta esperada deve apresentar o status `ok`.
